Drop the lofi hero image here as:  hero.jpg

The landing hero (public/index.html → .lp-hero) loads ./assets/hero.jpg.
If the file is missing, the hero falls back to a palette-matched CSS gradient
(.lp-hero-bg) so the page still looks intentional. Recommended: a wide
landscape image (≥ 1600px wide, 16:9-ish) — the same lofi "coding by the
window at sunset" frame used in the design.
